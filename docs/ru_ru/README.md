Клиентская очистка кеша для Minecraft: для установленных модов и для ресурспаков,
которые они используют. Устаревший кеш это причина, по которой игра рисует
неправильно: модели пропали и стали чёрно-фиолетовыми, текстуры не обновляются,
ресурспаки ломаются. CleanMCMod убирает это с одного экрана, сначала показывает,
что будет удалено, и по просьбе обновляет моды с Modrinth.

## 🧹 Что удаляется

- `logs/`, `crash-reports/` и отладочные дампы игры
- кеш ресурспаков, которые присылает сервер
- перепакованные jar файлы Fabric и отладочный вывод Mixin
- глубокий кеш ресурсов, по умолчанию выключен
- папки кеша в `config/<mod>/`, включая карты VoxelMap и Xaero, выключены по папкам

Каждая цель измеряется перед удалением. Папки никогда не удаляются сами, только
файлы; символические ссылки не прослеживаются; `saves/`, `mods/*.jar`,
`resourcepacks/`, `shaderpacks/`, `screenshots/` и `config/*.json` верхнего уровня
остаются нетронутыми.

## 🎮 В игре

- **F7** открывает экран, и на экране заголовка есть кнопка
- `/cleanmcmod scan`, `/cleanmcmod clean` и `/cleanmcmod screen` из чата
- строка **пробного запуска** говорит, что ничего не удаляется, пока она включена

## ⚙️ Настройки

Восемь переключателей, сохраняются сразу в `config/cleanmcmod.json`.

## ⬆️ Обновление модов

Спрашивает у Modrinth более новую сборку ваших jar. Сначала всё проверяется,
старый jar остаётся на месте, пока новый не готов. Свой собственный jar не
заменяется никогда.

## 🧩 Поддерживаемые версии

1.21.8 до 1.21.11 из одного кода с `-Pmc=<version>`, а 26.1, 26.2 и 26.3 из
отдельных ветвей на Java 25.
