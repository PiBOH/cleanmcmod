every translation. Each language the mod ships has one page under
`docs/<locale>/`, where `<locale>` is the file name used in
`src/main/resources/assets/cleanmcmod/lang/`. The Italian page is named
`LEGGIMI.md`; every other page is `README.md`.

These pages are short on purpose: what the mod does, the keys and the commands,
the settings, and how an update is installed. The build instructions and the
publishing notes stay in the English README, because they are for people working
on the source, not for players.

## 🤖 A word about the translations

Every page in this folder, and the mod's own texts, were translated with the
help of AI. They are reviewed, but a wording can still be wrong or out of date;
when in doubt, the English page wins. If you find a mistake, an issue or a pull
request that fixes the single line is welcome.
