Supported versions

Seven release branches, one per Minecraft version. Each one is pinned to its Fabric API and Mod Menu builds and has its own CI workflow, so a jar can be built and published for that version alone.

Java requirements

1.21.x branches
Java 21, Yarn mappings, remapping Loom (fabric-loom)
26.x branches
Java 25, official class names, non-remapping Loom (net.fabricmc.fabric-loom)
Gradle and Loom
always run on JDK 25, on every branch
fabric.mod.json
declares java >= 21 on 1.21.x and java >= 25 on 26.x
Why two toolchains: Minecraft 26.1 and newer ship unobfuscated, so there are no Yarn mappings and no remap step; the code compiles against the official names instead. That is why the 26.x line lives on separate branches rather than in one source tree with the 1.21.x line.

Release notes

  • Each branch builds exactly one jar: ./gradlew clean build in the branch, artifact in build/libs/.
  • That jar is the file published on Modrinth for its game version (loader: Fabric, environment: client).
  • CI builds and tests every branch on each push; the workflows are build-<version>.yml.
  • The project icon is logo.png at the repository root, with a 64 pixel variant in logo-64.png.
  • Mod Menu is optional on every branch: the jar only suggests it.
