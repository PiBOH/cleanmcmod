CleanMCMod

One screen that deletes the caches which make Minecraft render wrong, and keeps your mods up to date.

Stale caches are the usual cause of purple-and-black missing models, textures that never refresh and resource packs that stay half broken. CleanMCMod measures every cache first, shows what it is about to remove, and only deletes inside the folders the game itself regenerates. It can also read mods/, ask Modrinth for newer builds matching your game version and loader, and install them after you confirm.

Nothing happens by accident: a clean runs with a dry run on request, directories are never removed themselves, symlinks are never followed, and saves/, mods/*.jar, resourcepacks/, shaderpacks/, screenshots/ and top-level config/*.json are never touched.

Updating mods

Update mods… reads mods/, asks Modrinth for a newer build of each jar that matches the running game version and loader, and lists what it found. Nothing is installed until you press Install selected or Install all and confirm the list.

  • Every download is verified against the SHA-1 Modrinth publishes.
  • The old jar is moved aside, the new one moved in, and the old one restored if anything fails.
  • A missing required dependency is fetched at the same time, and nothing is downloaded if it cannot be resolved.
  • CleanMCMod never replaces its own jar while it is loaded.
  • Offline, unknown project, no matching version, unreadable jar, hash mismatch: mods/ stays exactly as it was, with one readable message.
